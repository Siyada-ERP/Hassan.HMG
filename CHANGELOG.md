## [1.0.0] - 2026-11-02

First version organised as a repository. It contains everything built so far.

### Application
- Double-entry posting engine with consistency checks; no formulas anywhere.
- Sales and purchase invoices, returns, receipt / payment vouchers, expenses, income, transfers, manual journal entries.
- Items with moving-average cost, reorder level, price lists; per-item **weight** (kg / litre per unit) with automatic **pieces = quantity ÷ weight** on invoice lines.
- **Sales / purchase registers** (one row per invoice with line count, expandable lines, view / edit / delete) and **net quantity after returns** per customer, supplier or item over a period.
- Reports: general ledger, trial balance, income statement, balance sheet, party statements, treasury, VAT report, e-invoice (ETA) draft, year-end closing.
- **Employees**: master data, advances and repayments, monthly payroll with advance deduction, payslip, employee statement and monthly advances sheet.
- Dexef-style **top menu bar** (headings with drop-downs and fly-outs, mobile drawer) replacing the sidebar.
- Company name entered once and applied to every screen, report and print header.
- Import of the CSV export of the Excel ERP, tied out to the cent.

### Server
- Multi-company, multi-user Node.js server (no npm dependencies, SQLite via `node:sqlite`).
- Roles: owner, accountant, viewer — enforced server-side.
- Invitations, e-mail verification and password reset (SMTP optional), activity log, admin console, CLI.
- Diff-based sync with conflict detection, long-poll updates and server-allocated document numbers; employees included in sync.
- Daily automatic backups, Docker + Caddy (automatic HTTPS) and systemd deployment files.

### Repository
- Layout `client/ server/ scripts/ tests/ docs/ .github/`; one `npm run build` produces `dist/SIYADA.html`.
- Tests: engine tie-out (2 fixture sets), 108 server assertions, 9 browser suites run by `tests/e2e/run_all.py`.
- GitHub Actions: CI (build, engine, server, browser, Docker) and tag-driven release.
- Anonymised fixtures and `scripts/anonymize_fixtures.py`.
